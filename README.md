# 💼 My Portfolio - Very Lucky

A modern, responsive portfolio website built using **React**, **TailwindCSS**, **Radix UI**, and **React Router DOM**. It showcases my projects, skills, and contact information as a frontend developer.

## 🚀 Live Demo

👉 [View Portfolio](https://your-portfolio-link.vercel.app)

## ✨ Features

- 🌐 Fully responsive and mobile-friendly
- 💡 Smooth navigation with React Router
- 🎨 Clean UI with TailwindCSS + Radix UI components
- 💼 Project showcase with live demo and GitHub links
- 📱 Contact form with basic validation
- 📸 Hero section with image and personal introduction

## 🛠️ Tech Stack

- **Frontend:** React, TypeScript
- **Routing:** React Router DOM
- **Styling:** TailwindCSS, Radix UI
- **Icons:** Lucide, Radix Icons
- **Deployment:** Vercel
